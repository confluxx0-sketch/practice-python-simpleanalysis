# Учебная практика. Python

Репозиторий содержит программный код для индивидуального задания
«SimpleAnalysis» по учебной (ознакомительной) практике.

## Запуск программы
1. Установить зависимости:
   pip install -r requirements.txt
2. Запустить программу:
   python simple_analysis.py

Результаты работы программы выводятся в консоль и отображаются в виде графиков.
